# Redacted original-result previews

The PNG figures in `01_figures/` are public copies of actual research figures. Their original spatial patterns, chart marks and relative positions remain visible. Selected sample or condition labels, gene or pathway labels, numerical scales, statistical annotations and conclusion text are obscured.

- `01_spatial_programmes.png`: spatial gene-programme expression.
- `02_pathway_enrichment.png`: spatial pathway-enrichment results.
- `03_cluster_associations.png`: cluster-level expression and enrichment relationships.

The treatment follows the project's poster portfolio: sensitive source-text pixels are removed first, then replaced by neutral blurred placeholders. The previews are saved as fresh, flattened raster images. They contain no hidden original text layer, editable chart data or result-table attachments.

These are redacted original figures, not schematic or simulated results. Visible chart shapes remain informative, but the withheld scales, identities and study context limit interpretation. Full originals and numerical results are retained privately. The main repository [README](../README.md) describes the project, and [METHODS](../METHODS.md) describes the scientific calculations. No scientific analysis was rerun to prepare these previews.
