# Preliminary analysis

Selected optional methods are retained alongside the main workflow: AUCell seed sensitivity examines random tie-breaking, and ordinary Spearman diagnostics calculate nominal cluster-level p-values. These functions have not been executed as part of the public template preparation. They do not establish spatially calibrated significance or a difference between experimental groups.

`01_scripts/` and `02_results/` remain paired. This public selection is not the complete private exploratory history.
