# Methods and input contract

This public code is a compact, portable adaptation of the project methods. It contains no research count matrix, fitted object, observed score, statistical result or tissue image. Original scientific files and complete execution history are retained separately. These templates have been reviewed and parsed, but have not been run on the private research data. They are not a claim that an original analysis has been reproduced.

## Inputs and software

Run R from the repository root. Supply one row per tissue section in a private copy of `04_data/sample_manifest_TEMPLATE.csv`. `spaceranger_dir` points to the sample directory containing `outs/`, not to `outs/` itself. Paths may be absolute or relative to the repository root. The importer expects filtered HDF5 counts and low-resolution spatial assets readable by `VisiumIO::TENxVisium`. Preserve Ensembl IDs, gene symbols, spot barcodes, in-tissue labels, array row/column coordinates and image coordinates. The mitochondrial pattern `^mt-` and marker symbols are for mouse data.

Use a compatible R/Bioconductor environment with BiocIO, VisiumIO, SpatialExperiment, SummarizedExperiment, SingleCellExperiment, scuttle, scran, SpotSweeper, Banksy, igraph, SpaNorm, Matrix, msigdbr, AUCell, BiocParallel and nnSVG. Package installation and version resolution are deliberately separate from analysis. The templates record installed versions, session information and local-outlier defaults at run time. No lockfile or fully tested environment is supplied; package compatibility and diagnostics must be checked in the intended environment. The Hallmark collection is retrieved at run time, so its version and returned memberships are saved with each run.

## Main workflow

1. Import filtered Visium counts and keep in-tissue spots. Feature display names are made unique while original identifiers remain in row metadata.
2. Flag spots with fewer than 400 UMIs, fewer than 300 detected genes or mitochondrial UMI percentage above 20%. Combine those flags with SpotSweeper local-outlier calls for library size, detected genes and mitochondrial percentage. Remove flagged spots, then all-zero genes. Other SpotSweeper arguments retain installed defaults, which are recorded. The earlier artifact diagnostic is omitted; it did not determine the discard rule.
3. Compute standard `scuttle::logNormCounts` expression, model gene variance with `scran::modelGeneVarByPoisson`, and select up to 1,000 HVGs. This branch supplies the clustering input.
4. Run BANKSY on the HVG subset using array coordinates, 20 geometric neighbours, lambda 0.8, 10 PCs and no azimuthal Gabor filters. Build a Jaccard SNN graph with 20 neighbours; run Leiden using modularity and resolution 0.6. Clustering is separate for each section. Original image coordinates are preserved on the full object. Equal cluster labels across sections do not establish matching cell types or anatomy.
5. Separately fit SpaNorm to the QC counts, with size factors set to total UMI/10,000. Use the negative-binomial model, `logpac`, sample fraction 0.25, scale factor 1, spline degrees of freedom 6 and lambda 0.0001; other explicit fitting controls are in `config.R`. The resulting `logcounts` assay is already log2(1 + PAC). Do not log-transform it again.
6. Average three SpaNorm gene values per spot for each fixed marker programme: Naive (Ccr7, Sell, Tcf7), Effector (Gzma, Gzmb, Bhlhe40), and Memory (Il7r, Cd27, Tcf7). These literature-associated panels are not a ranking of the most informative genes, cell-type assignments or AUCell pathways. All three genes must map unambiguously. SVG support is not used to select or remove programme members.
7. Retrieve the human Hallmark collection mapped to mouse with msigdbr. Use the shared Ensembl universe across all input sections and score every set with at least five measured genes. AUCell uses normalized AUC with cutoff `ceiling(universe_size * 0.05)`, covering approximately the top 5% of the shared ranked universe; ranks below that cutoff contribute to the score. A continuous seed stream runs through sections in manifest order; random ordering of tied expression values can affect scores. The selected downstream comparisons use TNF-related inflammatory and DNA-repair signatures. AUCell scores are not percentages or direct measurements of pathway activity.
8. Test each unique programme gene separately with nnSVG on SpaNorm expression and original spatial coordinates. Eligibility requires raw counts of at least three in at least `ceiling(0.005 * number_of_spots)` spots. Eligible fits retain every spot, including zeros, and use ten neighbours, AMMD ordering and serial execution. Convert the likelihood-ratio statistic with a two-degree-of-freedom chi-square tail, retaining a log-probability calculation for numerical stability. Apply BH across the predeclared section-by-gene request family. Untested requests contribute an internal p-value of one to adjustment but have no reported p or q. Sparse, untestable, unsupported and supported outcomes remain distinct. Boundary estimates and captured warnings require review; nnSVG may suppress some internal fitting warnings.
9. Average the previously calculated programme values and AUCell scores within each existing spatial cluster. Compute descriptive Spearman correlations between cluster-average Effector expression and each selected signature. Spot matching uses identifiers. A cluster contributes one point regardless of its size; these are cluster-level associations, not tests of an age or infection effect.

The code retains explicit methods and parameters while replacing private input aliases, fixed observed-count assertions and source-specific result statements with portable checks. It omits original plotting, alternate clustering branches, presentation assembly and execution infrastructure. The public preliminary folder retains selected optional diagnostics; the archive folder retains a historical CP10K alternative. Neither is silently mixed into the main analysis.

## Running the template

Make a private manifest under `04_data/local/`, replace the template paths and labels, then run explicitly:

```r
source("01_main_analysis/01_scripts/10_run_workflow.R")
result <- run_main("04_data/local/sample_manifest.csv")
```

Sourcing files alone does not execute scientific work. A run writes private objects, tables, parameters and version information to `01_main_analysis/02_results/generated/`, which is ignored by Git. Existing output directories are not overwritten. Set `SPATIAL_RESULTS_DIR` to a new private directory to choose another destination. A failed run can leave partial outputs; only a completed run writes `RUN_STATUS.txt`. These templates do not generate publication figures or infer biological conclusions automatically.

For optional diagnostics, source the relevant preliminary module and explicitly call its function with the returned main-workflow objects. AUCell seed sensitivity compares seeds 123, 124 and 125. Ordinary Spearman diagnostics use `cor.test(..., method = "spearman", exact = TRUE)`; R's exact/approximate calculation depends on sample size and ties, and warnings are retained. These nominal p-values are not spatially calibrated and do not test a difference between age groups. The historical CP10K function requires original full-library UMI totals, not totals recomputed after restricting gene rows. Unlike the main SpaNorm programme function, this historical method sums raw counts for exact duplicate gene symbols, retains missing genes as NA, and reports a programme only when every member is present. It returns scores, gene-expression values and coverage together.

## Interpretation limits

Spatial spots can contain mixed cell populations. Marker expression, rank-based pathway enrichment and nnSVG p-values measure different things and must keep their distinct units and meanings. A DNA-repair expression signature does not directly measure repair capacity. Descriptive comparisons of sections or their clusters do not establish biological replication, causation or cell communication. Evaluate input quality, model diagnostics, software versions, spatial dependence and study design before making an inference.
