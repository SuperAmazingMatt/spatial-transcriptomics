# Main analysis

`01_scripts/` contains the ordered method modules and an explicit workflow function. Standard logcounts and HVGs supply BANKSY clustering; SpaNorm supplies separate programme, AUCell and nnSVG readouts. See the repository's `METHODS.md` for inputs, parameters, usage and limitations.

`02_results/` is paired with these scripts. Research outputs remain private; an explicit local run writes to its ignored `generated/` directory.
